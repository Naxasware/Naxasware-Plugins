# Naxasware-Plugins

Naxasware's [Claude Code](https://code.claude.com) plugin marketplace. One self-contained plugin per folder under `plugins/`.

## Install
```bash
claude plugin marketplace add Naxasware/Naxasware-Plugins
claude plugin install <plugin-name>@naxasware-plugins
```
Other agents: each release has a `<skill>.full.md` file you can use as a system prompt.
