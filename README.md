# Naxasware Plugins

Naxasware's Claude Code plugin marketplace. One plugin per folder, one repo to add.

```bash
claude plugin marketplace add Naxasware/Naxasware-Plugins
claude plugin install <plugin-name>@naxasware-plugins
```

Each plugin works three ways: as a Claude Code plugin (above), as a `.skill` upload for claude.ai / Claude Desktop / Cowork, and as a flattened `.full.md` instruction file for non-Claude agents. Every [release](../../releases) attaches all three.

## Repository layout

```
Naxasware-Plugins/
├── .claude-plugin/marketplace.json   # generated - lists every plugin
├── plugins/<plugin-name>/            # one self-contained plugin per folder
│   ├── .claude-plugin/plugin.json
│   ├── skills/<skill-name>/SKILL.md (+ references/, scripts/)
│   ├── README.md, CHANGELOG.md
│   └── ci-smoke.sh                   # optional plugin-specific test
├── templates/plugin-template/        # scaffold for new plugins
├── scripts/                          # validate, sync, scaffold, package (stdlib-only Python)
├── claude-project/                   # instructions + knowledge to run this repo from a Claude Project
├── docs/                             # ADDING-A-PLUGIN, AUTOMATION, RELEASING
└── .github/                          # workflows, issue/PR templates, dependabot
```

## Adding or updating a skill

```bash
python3 scripts/new_plugin.py my-plugin --display "My Plugin" --description "What it does and when to use it."
# edit plugins/my-plugin/skills/my-plugin/SKILL.md
python3 scripts/validate_all_plugins.py .
git add -A && git commit -m "feat(my-plugin): initial release" && git push
```

On push, CI validates every plugin and skill, and the sync workflow updates `marketplace.json` and the table above automatically. To publish, tag it: `git tag my-plugin-v0.1.0 && git push --tags`. Details: [`docs/ADDING-A-PLUGIN.md`](docs/ADDING-A-PLUGIN.md), [`docs/AUTOMATION.md`](docs/AUTOMATION.md), [`docs/RELEASING.md`](docs/RELEASING.md).

Prefer not to do this by hand? [`claude-project/`](claude-project/README.md) sets up a Claude Project that turns a skill instruction document into a ready-to-push plugin folder.
